# 調査：LinkedIn会社ページ運用ベストプラクティス（2026-06）

作成: 2026-06-16 ／ 用途: Consilegy会社ページの看板（タグライン/About）・CTA・本数の意思決定材料。
関連: [投稿計画-会社ページ-2026-07.md](投稿計画-会社ページ-2026-07.md)、[戦略まとめ](consilegy-戦略まとめ-2026-06-10.md)

## 結論（最重要）

**会社ページはオーガニックの「リーチを取る場所」ではない。** 個人プロフィールがエンジン、会社ページは①信頼の置き場（SEO/完成度）②増幅の基地③NL/front doorの受け皿。これは現行戦略「個人＝配信エンジン、会社＝体系・実績の置き場」を裏付ける。

- 会社ページのオーガニックリーチはフォロワーの**約2%**まで低下（7%→2%）。2024→2026初頭で**60〜66%減**。
- 個人プロフィールは会社ページの**約5倍のエンゲージメント / 2.75倍のインプレ**、ブランド可視性の**約90%**を担う。
- 投稿後60分以内に**3人以上がコメント**すると約**5.2倍**に増幅。peerはブランド投稿よりも個人投稿にコメントするため、会社ページは構造的に不利。

→ **示唆**: 会社ページ単体でリーチを追わない。山口さん（＋チーム5名）が**会社投稿を即コメント／リシェア**して個人の社会的グラフに載せるのが本筋。従業員リシェアで会社投稿は**5〜10倍**増幅、原文コメント付きならさらに上（リシェアより原文コメントが強い）。

## 1. 本数・頻度

- **週1が最低ライン**：週1以上投稿する会社ページはしない所より**フォロワー増5.6倍**。
- **スイートスポットは2〜3回/週（月8〜12本）**。ただし「量より質」。3倍少なく投稿した会社が**2.2倍**の有効リードを獲得した事例も。
- 24時間に複数投稿すると自社内で枠を食い合う。
- → **Consilegyへの含意**: 現行の「JA＋EN ほぼ毎日」は過剰の可能性。**週1（JA＋翌日EN）への減速は◎**。最低ラインは死守。質を上げる方向で正しい。

## 2. 投稿フォーマット

- **動画（ネイティブ＋字幕）がリーチを最も広げる**とLinkedIn公言。短尺/長尺を試す。
- **80/20ルール**：80%は教育・洞察・娯楽、20%だけ自社宣伝。
- ハッシュタグは**3〜5個**。
- **最適時間**：B2Bは火〜木、7〜9時／12〜13時。→ 現行の**火〜木08:00は最適帯に合致**。
- → **含意**: 現行フォーマット（構造洞察＋画像）は良い。**月1〜2本は動画**を混ぜる。宣伝色は2割以下を維持（既存は問い締めでCTA無し＝合致）。

## 3. 看板（タグライン / About）最適化 ← 二層併記の設計根拠

- **タグライン**：上限120字。冒頭に**キーワードを先頭配置**。「何を・誰に」を平易に。推奨は60〜80字程度の簡潔さ。検索結果・フィードで社名の下に出る。
- **About/Overview**：最大2000字。**キーワードリッチ**に。Specialties欄に提供サービスのキーワードを列挙（SEO）。
- **完成度100%のページは閲覧+30%**。ロゴ/バナーは**キーワードを含むファイル名**で。カスタムURLをブランド名に。
- → **含意**: 二層併記の看板は、**JA/ENそれぞれで「キーワード先頭→何を誰に→現場定着の差別化」**を満たすよう書く。Specialtiesに「レベニューアーキテクチャ/RevOps/CRM/HubSpot/Salesforce/BtoB/営業・マーケ連携」等を入れる。

## 4. 多言語（二層併記）の正解 ← ユーザー選択を裏付け

- LinkedIn企業ページは**名前・説明・タグラインを20言語以上でローカライズ可**。閲覧者の言語設定で**自動出し分け**。未設定言語はデフォルト言語が表示。
- **「単一ページ＋複数言語ローカライズ」は、2つの言語オーディエンスを持つ小規模B2Bに最適**と明記（＝Consilegyの状況そのもの）。
- 翻訳投稿は**ビジュアルを変える**と重複コンテンツ感を回避できる。
- → **含意**: 山口さんの選択（**JAデフォルト＝②、ENローカライズ＝①**）は教科書的に正しい。看板はローカライズ機能で出し分け、投稿はJA→翌日ENの別投稿（画像は流用可だが文言最適化）。

## 5. front door / CTA（収益診断の扱い）← Q2「市場調査して」への回答

- 会社ページは**カスタムボタン1つ**を設置可（例: Contact us / Learn more / Sign up 等）。**最有力の変換装置**。
- **Featuredセクション**に最高実績の投稿・事例・リードマグネットを**ピン留め**。
- **LinkedInニュースレターは開封30〜40%**（通常メール15〜25%）。購読者にメール＋アプリ通知が毎号届く＝強力なリード資産。
- 端から端まで最適化した会社ページは**30日で閲覧2〜3倍**。
- → **含意（収益診断の出し方）**: Aboutに長いCTA文を足すより、**①カスタムボタンを収益診断（または問い合わせ）に設定 ②収益診断/事例の投稿をFeaturedにピン ③Aboutは末尾に1行の軽い導線**——の三点が定石。各投稿末尾に毎回CTAを足すのは80/20の宣伝2割を圧迫するので不要。**ボタン＋ピン＋NLが本線**。診断ページ未公開なら、まずボタンを「お問い合わせ」、公開後に診断へ差し替え。

| 判断 | 調査が示す答え |
|---|---|
| 二層併記（JA②/EN①） | ◎ 小規模B2B×2言語の最適解。ローカライズ機能で出し分け。 |
| 収益診断CTAをAboutに明示するか | △ Aboutベタ書きより**カスタムボタン＋Featuredピン＋NL**が定石。Aboutは軽い1行に留める。 |
| 7月の本数（週1） | ◎ 週1は最低ライン超え。毎日JA+ENからの減速は質向上で妥当。 |
| 投稿フォーマット | ○ 現行（構造洞察＋画像）維持。月1〜2本動画を追加。火〜木08:00は最適帯。 |
| 最大の伸びしろ | **山口さん＋チームが会社投稿を即コメント/リシェア**して個人グラフに載せる（5〜10倍増幅）。会社単体でリーチを追わない。 |
