# 収益診断 結果送付メール

診断でメールアドレスを受け取っている以上、結果を返す。現状は画面に出るだけで、
タブを閉じると消える（結果は sessionStorage にしか残らない）。

## 前提（実装ずみ・2026-08-26）

| 項目 | 値 |
|---|---|
| 結果のURL | contact プロパティ `consilegy_result_url` |
| 結果の要約 | contact プロパティ `message`（既定のMessage） |
| 経路 | `consilegy_lead_channel`（marketing / referral / mixed） |
| 業種 | `consilegy_industry` |
| フォーム | JA `df40a4b0-05e6-4fef-af58-633c398a619e` / EN `4276bb20-a017-42b2-bc83-404b579ff9fa` |

`consilegy_result_url` は回答した選択肢のインデックスだけを含み、個人情報は含まない。
開くと本人が見たのと同じ結果が再現される。営業側が「相手が何を見たか」を開くのにも使える。

## APIでできなかったこと

- ワークフロー作成 → `workflows-access-public-api` 権限が必要（automationスコープだけでは通らない）
- 自動化メールの公開 → `transactional-email` 権限が必要

どちらもプラン側の制約。**HubSpotの画面で設定する。**

## 設定手順

1. マーケティング → E メール → 「E メールを作成」→ **自動化**を選ぶ
2. テンプレートは Plain email。下の本文を貼る
3. 差出人: Consilegy 合同会社 / 返信先 seiko.yamaguchi@consilegy.com
4. 保存して自動化用に公開
5. 自動化 → ワークフロー → コンタクトベース
   - トリガー: フォーム送信「収益構造 成熟度診断 リード獲得」
   - アクション: 上のメールを送信
   - 英語版は EN フォームで同じものをもう1本

同じ文面のドラフトを API で作成ずみ（ID: JA `387109940966` / EN `387109940969`）。
ただし種別が BATCH_EMAIL になっているため、そのままでは自動化に使えない。
**本文のコピー元として使い、メール自体は自動化として作り直す。**

## 判断が残っている点

**配信の購読区分。** 既存の自動返信（資料ダウンロード返信）は「Consilegy ニュースレター」区分。
同じ区分にすると、ニュースレターを配信停止した人には診断結果も届かない。
本人が求めた結果なので、区分を分けることも検討する。
