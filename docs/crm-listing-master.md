## 3. カテゴリ

媒体側の選択肢に合わせるが、優先順は固定する。

1. CRM / 顧客管理システム（第1カテゴリ。必ず選ぶ）
2. SFA / 営業支援システム
3. 業務自動化・ワークフロー（選択肢がある場合のみ）
4. AI活用ツール（選択肢がある場合のみ）

MA・メール配信・BIは**選ばない**。機能はあるが主戦場ではなく、専業製品と比較されると不利。

## 6. 強み3点

順番も固定する。

1. **入力させないCRM**。名刺、手書きメモ、通話をAIが読み取って記録にする。担当者が打ち込む前提を外した。
2. **RevOps自動化175本を標準搭載**。設定を作り込まなくても、案件の停滞検知やフォロー漏れの通知が最初から動く。
3. **業種別に初期設定済みで届く**。B2B、受託開発、スクール、B2Cで用語もステージも変わる。空のCRMを渡さない。
