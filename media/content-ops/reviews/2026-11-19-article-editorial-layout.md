# 記事ページの編集レイアウト改修

本人指示「日本企業の記事っぽい見た目に」に対応。新規記事の追加・本文の改稿は行わず、公開中の日英記事209本の共通テンプレートを更新する。

タイトル、説明文、編集部署名、公開・更新日を一つのヘッダーに整理。記事の既存principleを要点欄へ移し、開閉可能な目次、本文の見出し、正典リンク、編集部情報、相談欄を整理した。PCは本文と関連記事の2列、スマートフォンは1列。既存の画像版URL、canonical、hreflang、Articleデータを維持する。画像生成・画像の差し替えは実施していない。署名は実態に合わせ編集部のまま。

参照した画面はITmedia https://www.itmedia.co.jp/itselect/sfa/article/9203/ とSalesforce https://www.salesforce.com/jp/blog/jp-sales-trends-report/ 。情報の階層を参考にし、記事の事実や統計は転用していない。

## 検証

- 最新origin/main 074220aを取り込んだ独立作業コピーで実施。他セッションの変更は含めない。
- 本体 npm run build 成功（386ページ）、media npm run build 成功（228ページ）。
- 生成した209記事でH1が1つ、目次フラグメント実在、記事画像ファイル実在、JSON-LDの構文を確認。エラー0。
- ローカルJA/ENのPCおよび390px表示を目視。JA本文幅はPC736px、スマートフォン342px。本文16px、H2はPC28px・スマートフォン24px。横方向のページはみ出しなし。
- バージョン付きの画像URLでヒーローと関連記事画像が表示されることを確認。元画像や既刊すべての個別画像を再審査した記録ではない。
- 今回は共通UI変更。新しい本文の人による独立編集審査・本人全文審査を実施したとは扱わない。
- push・GitHub Actions・本番反映は実行結果を別途報告する。
